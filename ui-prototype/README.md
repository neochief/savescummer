# Save Scummer UI prototype

Open `index.html` in Chrome or Safari. It is a single self-contained file: fonts, icons and game artwork are inlined.

Tweaks (in the design tool) or code let you switch layout: Game running / None running / No games.

Try: Save, Load, the history LOAD/REVERT buttons, delete (3 s countdown), clicking label chips, the Load badge, switching games, and editing Saved labels. Open Settings, Add custom game, Configure paths and Flush checkpoints to see the dialog designs and their validation states.

Decisions made in this prototype are recorded in [PLAN-UI.md](../PLAN-UI.md#prototype-decisions).
